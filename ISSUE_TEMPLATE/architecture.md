Use this template when proposing changes that affect more than one
person's work, change the shape of the system, or commit the team to
something hard to reverse. Examples:

- Changing the language, framework, or runtime of an existing app
- Replacing a major dependency (DB, ORM, auth, deploy infra)
- Introducing a new application, service, or repo
- Rewriting more than ~20% of an existing codebase
- Changing public API contracts
- Changing data models requiring migration
- Introducing a new external paid service

If you're unsure whether something qualifies, ask. The cost of asking
is small.

Code that bypasses this process should not be merged regardless of
quality.
